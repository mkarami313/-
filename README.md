# همراهِ طیف (HamraheTeyf)

یک اپلیکیشن اندرویدی فارسی‌زبان و راست‌چین برای ایجاد فضایی حمایتی، محترمانه و **رایگان** برای خانواده‌های کودکان اوتیستیک و ارتباط آن‌ها با متخصصان و جامعهٔ همراه.

> ⚠️ این برنامه جایگزین پزشک، درمانگر، تشخیص حرفه‌ای یا خدمات اورژانسی نیست.
> در برنامه **هیچ پرداخت، اشتراک، تبلیغ یا قابلیت پولی** وجود ندارد.

---

## یک نگاه سریع

- **زبان/معماری:** Kotlin + Jetpack Compose + Material 3، معماری MVVM با لایهٔ داده مجزا.
- **backend واقعی (پیش‌فرض):** نسخهٔ ریلیز به سرور خودمیزبانِ پروژه وصل می‌شود
  (`https://proj.tizbin.org/hamrah/api/`). داده‌ها در PostgreSQL ذخیره و بین کاربران و اجراها
  ماندگار می‌مانند. سرور یک فایل پایتونِ بدونِ وابستگی است: [`server/`](server/README.md).
- **حالت نمایشی (DEMO):** با تغییر `BACKEND` به `DEMO` در `app/build.gradle.kts`، برنامه با دادهٔ
  آزمایشیِ درون‌حافظه‌ای و بدون هیچ شبکه‌ای اجرا می‌شود؛ همین حالت در آزمون‌های واحد استفاده می‌شود.
- کل منطق پشت واسط‌های repository قرار دارد، پس جابه‌جایی بینِ SERVER و DEMO هیچ تغییری در UI نمی‌خواهد.
- **حریم خصوصی‌محور:** اطلاعات کودک و مدارک تخصصی جدا و خصوصی نگه داشته می‌شوند؛ نشان «تخصص تأییدشده» فقط با تأیید مدیر داده می‌شود.

## اجرای سریع

۱. پوشهٔ پروژه را در **Android Studio** (نسخهٔ جدید، با JDK 17) باز کنید.
۲. منتظر همگام‌سازی Gradle بمانید و روی یک شبیه‌ساز/دستگاه اندروید (minSdk 24) اجرا کنید.
۳. در صفحهٔ ورود، با یکی از حساب‌های نمونه وارد شوید (رمز همه: `demo1234`):
   - خانواده: `zahra@example.com`
   - مدیر (برای دیدن پنل مدیریت): `admin@example.com`

جزئیات کامل: [`docs/RUN.md`](docs/RUN.md).

## ساختار پروژه

```
app/src/main/java/com/hamraheteyf/app/
├─ data/
│  ├─ model/            # مدل‌ها و enumها (User, Question, Group, …) + قواعد دسترسی در کامنت‌ها
│  ├─ repository/       # واسط‌های repository (قرارداد لایهٔ داده)
│  │  └─ fake/          # پیاده‌سازی درون‌حافظه‌ای + دادهٔ آزمایشی (حالت DEMO)
│  └─ DataResult.kt     # نوع نتیجه با پیام خطای فارسی
├─ di/                  # AppContainer (تزریق وابستگی ساده) + انتخاب backend
├─ ui/
│  ├─ theme/            # تم آرام، فونت، راست‌چین اجباری
│  ├─ common/           # اجزای مشترک (نشان‌ها، هشدارها، کارت‌ها، قالب‌بندی فارسی)
│  ├─ navigation/       # مسیرهای ناوبری
│  ├─ auth/ home/ qa/ groups/ messages/ guides/
│  ├─ directory/ notifications/ profile/ admin/ legal/
│  └─ AppRoot.kt        # ریشهٔ ناوبری (ورود ↔ بخش اصلی با نوار پایین)
├─ HamrahApplication.kt # نگه‌دارندهٔ AppContainer
└─ MainActivity.kt
backend/                # قوانین امنیتی Firestore و Storage (پیش‌نویس)
docs/                   # راهنمای اجرا، backend، ساخت APK، وضعیت قابلیت‌ها، امنیت
```

## قابلیت‌های پیاده‌شده

- ورود/ثبت‌نام با انتخاب نوع حساب، پذیرش قوانین، و خطاهای فارسی؛ خروج و حذف حساب.
- خانه با جست‌وجو، پرسش‌های تازه، گروه‌های فعال، راهنماها، و هشدار ثابت ایمنی.
- پرسش‌وپاسخ: ساخت (با دسته‌بندی و گزینهٔ ناشناس و هشدار)، پاسخ، علامت «مفید»، گزارش، ویرایش/حذف و بستن دیدگاه‌ها توسط نویسنده، مرتب‌سازی شفاف.
- گروه‌ها: ساخت عمومی/خصوصی، پیوستن/درخواست عضویت، تأیید عضو، پست و حذف، گزارش.
- پیام خصوصی متنی با جریان «درخواست → پذیرش»، بی‌صدا/مسدود/گزارش/پایان، و یادآوری عدم‌جایگزینیِ اورژانس. ارسال فایل در این نسخه غیرفعال است.
- فهرست و جست‌وجوی متخصصان با فیلترها و نمایش شفاف وضعیت تأیید.
- راهنماها و منابع با ذخیره، نویسنده، منابع و تاریخ بازبینی.
- اعلان‌ها با دسته‌بندی قابل خاموش‌کردن و محتوای غیرحساس.
- پروفایل و تنظیمات: ویرایش، حریم خصوصی، کاربران مسدودشده، درخواست نسخهٔ اطلاعات، حذف حساب.
- پنل مدیریت درون‌برنامه‌ای: گزارش‌ها، بررسی تخصص (با ثبت دلیل و گزارش تغییرات)، مشاهدهٔ مدرک با ثبت ممیزی.

وضعیت دقیق «کامل/نیازمند سرویس واقعی»: [`docs/STATUS.md`](docs/STATUS.md).

## آزمون‌ها

آزمون‌های واحد لایهٔ داده در `app/src/test/java/com/hamraheteyf/app/RepositoriesTest.kt`:
ورود، جداسازی دسترسی داده، ساخت پرسش/پاسخ، ساخت گروه و عضویت، گزارش محتوا، تفکیک نشان تأیید، و حذف حساب.

اجرا در Android Studio یا با `./gradlew testDebugUnitTest`.

## امنیت و حریم خصوصی

خلاصهٔ تصمیم‌ها در [`docs/SECURITY.md`](docs/SECURITY.md). نکات کلیدی: فقط HTTPS، نبودِ کلید در کد،
عدم چاپ اطلاعات خصوصی در log، تفکیک دادهٔ خصوصی کودک و مدارک، و مسیر روشن برای حذف داده.

> متن‌های قوانین و حریم خصوصی داخل برنامه **پیش‌نویس** هستند و ادعای انطباق حقوقی قطعی ندارند.
